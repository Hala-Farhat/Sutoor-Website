## 🌍 نحن هنا | About Us

**Sutoor Initiative** هي مبادرة شبابية تطوعية انطلقت من قلب غزة لحماية المستقبل التعليمي للطلاب في ظل الحرب. نحن ندعم الطلاب في غزة من خلال طباعة الملازم التعليمية، حلقات تحفيظ القرآن الكريم، الأنشطة المجتمعية، والدعم المدرسي المباشر.

**Sutoor Initiative** is a volunteer-led movement founded in Gaza to protect the future of education during conflict. We support students in Gaza through educational printing, Quran memorization circles, community activities, and direct school support.

---

## 🎯 مشاريعنا | Our Core Projects

### 1. **دعم الطباعة المنهجية | Educational Printing Support**
توفير المناهج والملازم الدراسية مجاناً أو بأسعار رمزية للطلاب، منع الطلاب من الدراسة عبر شاشات الهواتف المحمولة.

**Status**: 1,500+ students registered | 1,500+ طالب مسجل

### 2. **الدعم النفسي والترفيهي | Psychological Support Activities**
تنظيم فعاليات ترفيهية ومسابقات تعليمية لتخفيف الضغوطات النفسية التي يعاني منها الأطفال.

**Status**: 25+ workshops conducted | 25+ ورشة عمل منفذة

### 3. **حلقات تحفيظ القرآن الكريم | Quran Memorization Circles**
رعاية الحلقات القرآنية في مراكز النزوح، وتزويد الأطفال بالمصاحف والجوائز والحوافز.

**Status**: 150+ committed students | 150+ طالب ملتزم

### 4. **المبادرات المدرسية | School Initiatives**
دعم التجمعات التعليمية والخيام الدراسية بتوفير الدفاتر والقرطاسية والألواح.

**Status**: 4 temporary school sites | 4 مواقع مدارس مؤقتة

### 5. **الفعاليات التثقيفية | Educational Engagement Programs**
تأسيس نوادي القراءة والمناظرات الطلابية لتشجيع التعلم والتفكير النقدي.

**Status**: 12 interactive events | 12 فعالية تفاعلية

## 🚀 البدء السريع | Quick Start

### المتطلبات | Requirements
- **Node.js** v16 أو أحدث
- **npm** أو **yarn**

### التثبيت | Installation

```bash
# استنساخ المستودع
git clone https://github.com/yourusername/sutoor-initiative.git

# دخول المجلد
cd sutoor-initiative

# تثبيت المكتبات
npm install
```

### التطوير | Development

```bash
# بدء خادم التطوير
npm run dev
```

سيتم فتح الموقع تلقائياً على `http://localhost:5173`

### البناء للإنتاج | Production Build

```bash
# بناء الملفات المُحسّنة
npm run build

# معاينة البناء
npm run preview
```
